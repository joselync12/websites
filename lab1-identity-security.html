Results and Reports

The command manual and network tools in this lab connect several parts of TCP/IP communication. An IP address identifies a device on an IP network, the subnet mask distinguishes the local network from host addresses, and the default gateway forwards traffic to other networks. DNS provides the IP address associated with a host name. ARP resolves a local IPv4 address to a hardware address, while ping and traceroute provide different views of reachability and the path to a destination.

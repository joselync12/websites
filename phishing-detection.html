Machine Learning-Based Phishing Website Detection

Using Decision Tree and Random Forest models to spot dangerous websites

Project Overview

This cybersecurity project investigates whether machine learning can identify phishing websites using only numerical URL characteristics. I trained and compared two scikit-learn classifiers — a Decision Tree and a Random Forest — to distinguish legitimate websites from phishing ones by analyzing features like URL length, number of dots, presence of a shortened URL, and other structural signals.

The analysis uses the Web Page Phishing Dataset from Kaggle (100,077 records, 19 URL features). After removing exact duplicates, 21,891 records were used for training and evaluation.

Built with Python in Google Colab using pandas and scikit-learn. The full analysis lives in a Jupyter notebook with a final report PDF.

Results

Both models were evaluated on a held-out test set:

  • Decision Tree — 81.41% accuracy
  • Random Forest — 82.58% accuracy

The Random Forest model performed best, achieving approximately 94% recall for phishing websites — it caught nearly all dangerous sites in the test set. The trade-off is that it also flagged some legitimate websites as phishing (false positives), which is an important security consideration: false positives may block legitimate sites, while false negatives may let users reach phishing ones.

This project demonstrates that URL-based machine learning can support phishing detection, but it should not be the only layer of protection.
